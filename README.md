# Student Records Management API

A RESTful backend service built using **Node.js**, **Express**, and **MongoDB** (via Mongoose) to manage student records and course data.

## Features
- Create and manage courses (`/api/courses`)
- Add student profiles linked to courses (`/api/students`)
- Retrieve aggregate statistics and course marks (`/api/students/stats`)

## Tech Stack
- **Node.js** & **Express**
- **MongoDB** & **Mongoose**
- **Postman** (API Testing & Documentation)
